# 🏥 Hospital Emergency Room Dashboard

An interactive **Hospital Emergency Room Dashboard** built using Microsoft Excel to analyze patient visits, waiting times, demographics, referrals, admissions, and other emergency room insights.

## 🔍 Key Analysis

- 🏥 Total Patient Visits
- 👥 Patient Demographics
- ⏱️ Average Waiting Time
- 🚑 Admission & Referral Analysis
- 📅 Monthly Patient Visit Trends
- 🩺 Department/Referral Analysis
- 😊 Patient Satisfaction Analysis
- 📊 Emergency Room Performance

## 🎯 Project Objective

The objective of this project is to analyze hospital emergency room data and transform raw data into meaningful insights through an interactive Excel dashboard.

The dashboard helps understand patient trends, waiting times, demographics, referrals, admissions, and overall emergency room activity.

## 📈 Key Insights

The dashboard provides a visual overview of emergency room operations and helps identify patterns and trends in patient visits and hospital services.
